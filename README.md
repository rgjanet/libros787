# Libros787 — enlaces (versión GitHub Pages)

Este repositorio contiene la página de enlaces de Libros787 (`index.html`), lista para publicarse gratis con GitHub Pages.

## Cómo publicarla

1. **Crea un repositorio nuevo** en GitHub (por ejemplo `libros787-enlaces`).
2. **Sube `index.html`** a la raíz del repositorio (*Add file → Upload files* en la interfaz web de GitHub).
3. Ve a **Settings → Pages** dentro del repositorio.
4. En **Source**, elige la rama `main` (o `master`) y la carpeta `/ (root)`. Guarda.
5. Espera uno o dos minutos. GitHub te dará el enlace publicado, con este formato:
   - `https://tu-usuario.github.io/libros787-enlaces/`

## Antes de publicar

Reemplaza dentro de `index.html` todo lo marcado con `<!-- EDITAR: ... -->`:
- El video destacado (hero) — pon el ID real de tu video de YouTube.
- Los enlaces de la tienda, podcast, boletín, redes, programa de autores y correo.
- El episodio de podcast y el video de la sección "En el aire".
- Las fotos de "Desde la librería" (necesitan una URL pública — puedes alojarlas en este mismo repositorio).
- Las notas de prensa en "En la prensa".

## Dominio propio (opcional)

Si más adelante quieres usar un dominio como `enlaces.libros787.com` en vez de `tu-usuario.github.io`, en **Settings → Pages → Custom domain** puedes añadirlo, apuntando un registro CNAME desde donde administras el DNS de libros787.com hacia `tu-usuario.github.io`.
